Mission Briefings

Settings

Coordinates: planetocentric latitude, east-positive longitude 0–360°. Distances use a spherical Mars, mean radius 3389.5 km. Settings and routes are stored in this browser only.

Help & Documentation

Click the map to place route points. Distance is a great-circle (direct) path on a sphere, not a terrain-aware route. Direct routes are never labelled safe. The map tries to load NASA Trek Mars imagery; if it cannot be reached, a plain latitude/longitude grid is shown instead and everything else keeps working. Elevation along a route comes from a small MOLA grid file (mola_grid.json) that you generate once with make_mola_grid.py; without it, the profile is marked unavailable. CRISM minerals are not integrated yet.
